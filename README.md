# PRMAssist org defaults

GitHub applies the files here to every PRMAssist repository that does not have its own.

| File | Effect |
|---|---|
| `.github/pull_request_template.md` | Pre-fills the description of every new pull request |

The rules behind the template are in
[`docs/contributing.md`](https://github.com/PRMAssist/prmassist-infrastructure/blob/master/docs/contributing.md)
in prmassist-infrastructure (org members only).

**This repository is public**, because GitHub only applies org-wide defaults from a public
`.github` repository. Keep it to generic process files: no internal hostnames, names, data or links
that reveal more than a URL.
